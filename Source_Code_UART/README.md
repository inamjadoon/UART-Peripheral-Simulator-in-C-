# UARTSim

UARTSim is a small C++17 console project that demonstrates a simple UART transfer between two devices with a text-based setup menu.

## Build

```bash
build.bat
```

## Run

```bash
run.bat
```

Examples:

```bash
UARTSim
```

Arguments:

- Use the on-screen menu to choose message text, parity, stop bits, data bits, baud rate, and loopback.
